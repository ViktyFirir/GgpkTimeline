ГГПК через года - WPF (C#, .NET 8)

1. Установите Visual Studio 2022 (или новее) с нагрузкой ".NET desktop development".
2. Откройте GgpkTimeline.sln, нажмите F5.
3. Скопируйте шрифты Montserrat (.ttf) в папку GgpkTimeline\Fonts и пересоберите проект.
4. Замените картинки в GgpkTimeline\Assets (PreMain.png, LOGO.png, Silhouette.png) файлами с теми же именами.
5. Тексты и годы редактируются в GgpkTimeline\Data\timeline.json (в готовой сборке - Data\timeline.json рядом с exe, пересборка не нужна).
6. Картинки для периодов - GgpkTimeline\Images\Years\<год>.png

Управление: колесо мыши / стрелки / касание - прокрутка, кружки внизу - переход к году, Esc - выход.
